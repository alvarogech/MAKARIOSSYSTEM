## 8. Jornadas principais

### Jornada do primeiro acesso

```text
Cadastro/importação
→ matrícula
→ convite
→ criação de senha
→ aceite dos termos
→ dashboard
```

### Jornada de estudo

```text
Dashboard
→ volume
→ aula
→ vídeo
→ material
→ exercício
→ próximo conteúdo
```

### Jornada de avaliação

```text
Requisitos concluídos
→ avaliação liberada
→ tentativa
→ correção automática
→ resultado
→ validação ou recuperação
```

### Jornada de recuperação

```text
Nota abaixo de 6
→ trilha de revisão
→ revisão concluída
→ recuperação
→ nota final
→ validação
```

### Jornada de reposição

```text
Ausência
→ opção equivalente
→ solicitação
→ análise da coordenação
→ presença
→ validação
→ atualização da matrícula original
```

### Jornada de conclusão

```text
Critérios atendidos
→ apto para aprovação
→ validação da coordenação
→ aprovado
→ certificado de volume
```

### Jornada da formação completa

```text
Essência concluído
→ Caminho concluído
→ Voz concluído
→ validação final
→ formação completa
→ certificado completo
```
